# 江湖传说 - 世界观设定全景图

## 概述

《江湖传说》是一款架空武侠风格的文字游戏，以中国武侠文化为底蕴，构建了一个门派林立、世家争雄的江湖世界。

---

## 一、世界观背景

### 1.1 游戏设定

**世界名称：中原**

> 立国千年以来，江湖风云变幻。五大门派、三大世家、朝廷官府，各势力明争暗斗，在权力博弈中你来我往。然而，随着朝堂动荡，沉寂已久的古老敌人正在苏醒，江湖将再次面临浩劫。

**核心设定元素：**
- **中原** - 游戏世界所在的整个大陆
- **天阙城** - 皇都所在，权力中心
- **立国盟约** - 千年前订立的建国契约
- **九大势力** - 统治江湖的五大门派、三大世家与朝廷
- **古老敌人** - 沉睡千年的邪恶势力
